# SideQuest Site

A React/Vite landing page and app shell for the SideQuest experience.

## Getting started

1. Install dependencies:
   `npm install`
2. Create an environment file if needed, for example:
   `VITE_APP_ID=your_app_id`
   `VITE_APP_BASE_URL=https://your-backend.example.com`
3. Run locally:
   `npm run dev`

## Project structure

- `src/` – application source code
- `src/components/` – reusable UI and landing page components
- `src/lib/` – app utilities and shared logic
- `src/pages/` – routed page views
